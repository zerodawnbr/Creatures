## Descrição

Este repositório reúne minhas criações, modificações e melhorias em objetos 3D para DayZ, incluindo modelos desenvolvidos do zero e adaptações de modelos já existentes no jogo.

Em breve, novos objetos 3D estáticos serão adicionados, trazendo funcionalidades e possibilidades de interação com os jogadores, expandindo a imersão e as experiências de gameplay.
